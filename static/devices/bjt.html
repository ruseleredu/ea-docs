Equations and model

    

      
    
        
  • Transport currentICT = IS · (eVBE / VT − eVBC / VT) · (1 + VCE / VAF)The current carried from emitter to collector by carriers crossing the base, with the Early effect.
    • 
        
  • CollectorIC = ICT − (IS / BR) · (eVBC / VT − 1)
    • 
        
  • BaseIB = (IS / BF) · (eVBE / VT − 1) + (IS / BR) · (eVBC / VT − 1)
    • 
        
  • EmitterIE = IC + IBVBC = VBE − VCE, and VT = kT/q = 25.85 mV at 27 °C. For a pnp transistor read every voltage and current with the opposite sign.
    • 
        
  • CutoffIC ≈ 0Neither junction is forward biased, so both exponentials are negligible.
    • 
        
  • ActiveIC ≈ BF · IB · (1 + VCE / VAF)VBC is negative, so the terms in eVBC / VT drop out.
    • 
        
  • SaturationIC < BF · IBVBC is positive: the collector junction conducts too, and its terms subtract from the collector current and add to the base current.

Model: Ebers-Moll transport equations at 300 K with the parameters above. No breakdown and no high-current effects. The pnp version uses the same magnitudes with every voltage and current reversed. About one injected carrier in eight is shown recombining in the base so that the base current is visible; with a gain of 100 the real figure is about one in a hundred. The readouts and curves use the real equations.
